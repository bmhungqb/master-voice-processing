\section{Experiments}\label{sec:exp}

\subsection{Selected paper}
We use CopyNE~\cite{lin2024copyne} (Group B1, ACL 2024, rank A*) for the demo and the ablation study.
The other candidate was the CTC-based word spotter~\cite{andrusenko2024ctcws} (Group C). In favour of CopyNE:
\begin{itemize}
  \item The authors release code, a checkpoint and the evaluation manifests with annotated entities
    (\texttt{test-ne}: 2244 utterances, 3082 entities), so the paper's metrics can be recomputed.
  \item Evaluation is inference only, so it should fit a free T4 GPU (to be confirmed by the first run); training needs 4 GPUs and is not repeated.
  \item The context is a plain entity dictionary (a JSON file), so ablations on dictionary size and on the copy
    mechanism need no retraining.
  \item NE-CER measures errors on the entities directly, which is what context-aware ASR aims to reduce.
\end{itemize}
Known limits: the data are Mandarin (AISHELL-1), the upstream repository has no license file, and the paper reports
that many noisy dictionary entries hurt accuracy. \todo{Outcome of the first GPU run: checkpoint downloaded, smoke test passed or failed.}
