# Yêu cầu đồ án cuối kỳ

## 1. Sản phẩm nộp

| # | Sản phẩm | Định dạng | Yêu cầu |
|---|---|---|---|
| 1 | Báo cáo | PDF | Có danh sách nhóm và phân chia công việc cho từng thành viên |
| 2 | Slide trình bày | PDF | |
| 3 | Video | Video | 10-15 phút, gồm thuyết trình + demo |
| 4 | Folder sản phẩm liên quan | Folder | Data, code (C/C++/Java/Python/Notebook) kèm hướng dẫn chạy lại code, web/app, ... |

## 2. Nội dung và tiêu chí đánh giá

| Tỉ trọng | Nội dung | Yêu cầu chi tiết |
|---|---|---|
| **30%** | Khảo sát hiện trạng | Với topic đã chọn, trên thế giới (và trong nước) đang giải quyết như thế nào? Tìm **ít nhất 5 bài báo** trên tạp chí **Q1/Q2** hoặc hội nghị hạng **A/A\*** trong khoảng **3-5 năm** trở lại đây; đọc, tóm tắt, phân tích ưu/nhược điểm, ... |
| **20%** | Chạy demo | Có thể lấy code trên mạng, ... |
| **30%** | Hướng nghiên cứu hoặc ứng dụng | **(a)** Nếu chọn hướng nghiên cứu: làm **ablation study**. **(b)** Nếu chọn hướng ứng dụng: làm **web/app chạy được** |
| **20%** | Phân tích chuyên sâu | Chọn **1 giải pháp** và phân tích chuyên sâu, đề xuất cải tiến, hoặc hoàn chỉnh web/app |

## 3. Checklist

- [ ] Báo cáo PDF: danh sách nhóm + phân chia công việc
- [ ] Slide PDF
- [ ] Video 10-15 phút (thuyết trình + demo)
- [ ] Folder: data, code, hướng dẫn chạy lại, web/app
- [ ] Khảo sát ≥ 5 bài báo Q1/Q2 hoặc hội nghị A/A\* (3-5 năm gần đây), có tóm tắt và phân tích ưu/nhược điểm
- [ ] Demo chạy được
- [ ] Ablation study (hướng nghiên cứu) hoặc web/app chạy được (hướng ứng dụng)
- [ ] Phân tích chuyên sâu 1 giải pháp + đề xuất cải tiến / hoàn chỉnh web/app
